# MLOps Workshop – Prefect Pipeline Automation

This repository contains screenshots documenting my MLOps workshop using Prefect.

## Workshop Activities

- Machine Learning model training
- Model loading and evaluation workflow
- Code formatting with Black
- Code quality analysis with Pylint
- Security checks with Bandit
- Unit testing with Pytest
- Prefect deployments and scheduled pipeline execution
- Prefect Web UI monitoring

## Screenshots

The screenshots provide visual evidence of the different steps completed during the workshop.

## Technologies Used

- Python
- Prefect
- Black
- Pylint
- Bandit
- Pytest
- Git and GitHub

## Objective

The objective of this workshop is to understand how to orchestrate Machine Learning workflows, validate code quality, and schedule automated pipeline executions using Prefect.
